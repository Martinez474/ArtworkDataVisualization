# ArtworkDataVisualization

If you want to use this project in the Godot editor follow these steps.

1) Download the data from here http://imag.pub.ro/pandora/pandora_download.html

2) Unzip the folder and place into the root of the godot folder

3) rename folder to artworks

4) Go into sub folders and select all images and put them into the root of the artworks folder and delete empty folder. Repeat for all sub folders.
